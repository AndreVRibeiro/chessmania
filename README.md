# chessmania

Chess Mania is a 4-player team based chess game variant developed as student project for the University of Basel course "Programmierprojekt FS21". Be sure to check out the game manual to get started. You can find us on our website as well as on Youtube: TRAILER
See you on the board, chess maniac!
